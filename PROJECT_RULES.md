# PROJECT_RULES — VPS ARG Web

1. Trabajar sobre copia/branch de desarrollo; no sobrescribir producción sin aprobación explícita.
2. No modificar backend productivo, Nginx, DNS, secretos, pagos ni datos de clientes sin autorización expresa.
3. No eliminar funcionalidades, páginas, videos, formularios, endpoints ni contratos de API sin análisis y aprobación.
4. Antes de cambiar código: inspeccionar archivos y dependencias relevantes, describir alcance y riesgos.
5. Modificar exclusivamente lo necesario; evitar reemplazar archivos completos si basta un cambio localizado.
6. Verificar sintaxis, enlaces, rutas, recursos, pruebas y compatibilidad después de cada cambio.
7. No afirmar que una integración funciona si no se probó de extremo a extremo.
8. Mantener documentación de contexto, reglas, changelog, tareas, estructura y esquema de datos; declarar explícitamente lo no verificado.
9. El nombre visible del curso es “Curso ADM Redes VPN”.
10. La Academia contiene tutoriales de uso y administración de servicios; no alojar allí la página de venta del curso.
11. Los CTAs de servicios para comprar llevan a Compras; no reintroducir Planes como sección principal.
12. Header común: logo a la izquierda, hamburguesa a la derecha, contacto dentro del menú.
13. Conservar los enlaces actuales de WhatsApp y los destinos de navegación.
14. Diseño responsive sin desbordamiento horizontal en móvil, tablet, netbook, notebook y escritorio.
15. No usar credenciales reales en desarrollo; nunca solicitar ni exponer tokens o contraseñas.
