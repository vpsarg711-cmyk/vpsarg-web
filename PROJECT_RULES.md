# PROJECT_RULES — VPS ARG Web

- No borrar funcionalidades, rutas, videos, formularios o contenido aprobado sin autorización.
- No modificar backend, Nginx, DNS, secretos, pagos ni datos productivos sin aprobación explícita.
- Inspeccionar el código actual antes de cambiarlo; modificar solo lo necesario.
- No afirmar que algo funciona sin prueba; distinguir validación estática de prueba de navegador y end-to-end.
- Mantener documentación de continuidad actualizada.
- Conservar nombre “Curso ADM Redes VPN”, separado de Academia.
- Conservar enlaces y contratos de API existentes.
- Header: logo a la izquierda, hamburguesa a la derecha, contacto dentro del menú.
- El menú debe cerrar al tocar fuera, seleccionar una opción y presionar Escape.
- Mantener diseño responsive y evitar desbordamiento horizontal.
- Nunca solicitar ni exponer secretos.
